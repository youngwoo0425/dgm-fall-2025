## 1. Tensors in Deep Learning
- A **tensor** is a multidimensional array (generalization of scalars, vectors, matrices).  
- **Order (rank)** = number of indices (e.g., scalar=0D, vector=1D, matrix=2D, image batch=4D).  
- Central data structure in deep learning models.  

---

## 2. Tensors and PyTorch
- **NumPy vs PyTorch**: both provide tensor-like structures, but PyTorch adds:
  - GPU acceleration,
  - automatic differentiation,
  - deep learning convenience functions.  
- **Data types**: mappings exist (e.g., NumPy `float64` → PyTorch `DoubleTensor`).  
- **GPU usage**: `tensor.to(torch.device("cuda:0"))`.  
- Matrix multiplication: `torch.matmul`, `@`.
